# 📸 Modern Fotoğrafçılık Portfolyo Web Sitesi

Bootstrap 5.3.3 ile geliştirilmiş, 2026 tasarım trendlerine uygun modern fotoğrafçılık portfolyo sitesi.

## ✨ Özellikler

- 🌓 **Dark/Light Mode** - Kullanıcı tercihine göre tema değiştirme
- 📱 **Tam Responsive** - Tüm cihazlarda mükemmel görünüm
- 🎨 **Modern Tasarım** - 2026 trendlerine uygun gradient, animasyon ve efektler
- 🖼️ **Filtrelenebilir Galeri** - Kategorilere göre portfolyo filtreleme
- ⚡ **Hızlı ve Optimize** - Lazy loading ve performans optimizasyonları
- 🎭 **Animasyonlar** - Parallax, hover efektleri ve smooth transitions
- 📧 **İletişim Formu** - Çalışan form validasyonu

## 🚀 Kullanım

1. Repository'yi klonlayın:
```bash
git clone https://github.com/ozansonar/photography-portfolio-2026.git
```

2. `index.html` dosyasını tarayıcınızda açın

3. Kişiselleştirin:
   - Fotoğrafları değiştirin
   - İletişim bilgilerini güncelleyin
   - Renk şemasını özelleştirin

## 📁 Dosya Yapısı

```
├── index.html       # Ana sayfa
├── galeri.html      # Portfolyo galerisi
├── hakkimda.html    # Hakkımda sayfası
├── iletisim.html    # İletişim formu
├── style.css        # Ana CSS dosyası
└── script.js        # JavaScript fonksiyonları
```

## 🎨 Renk Özelleştirme

`style.css` dosyasındaki CSS değişkenlerini düzenleyerek renkleri değiştirebilirsiniz:

```css
:root {
    --primary-color: #6366f1;
    --secondary-color: #ec4899;
    --accent-color: #8b5cf6;
}
```
