## 🚀 Kurulum

### 1️⃣ Repository'yi Klonlayın
```bash
git clone https://github.com/ozansonar/photography-portfolio-2026.git
cd photography-portfolio-2026
```

### 2️⃣ Tarayıcıda Açın
**Yöntem 1:** Direkt olarak
```bash
open index.html  # macOS
start index.html # Windows
xdg-open index.html # Linux
```

**Yöntem 2:** Local Server ile
```bash
# Python 3
python -m http.server 8000

# PHP
php -S localhost:8000

# Node.js (npx http-server)
npx http-server -p 8000
```

Ardından `http://localhost:8000` adresine gidin.

### 3️⃣ GitHub Pages ile Yayınlayın
1. Repository Settings > Pages
2. **Source:** Deploy from a branch
3. **Branch:** main / **Folder:** / (root)
4. **Save** butonuna tıklayın
✅ Siteniz yayınlandı: `https://ozansonar.github.io/photography-portfolio-2026/`

## 🎨 Kişiselleştirme Rehberi

### Renk Şemasını Değiştirin

`style.css` dosyasını açın ve `:root` bölümündeki değişkenleri düzenleyin:

```css
:root {
    /* Ana Renkler */
    --primary: #FF6B6B;      /* Kırmızı/Turuncu */
    --secondary: #4ECDC4;    /* Turkuaz */
    --accent: #FFE66D;       /* Sarı */
    
    /* Arka Plan */
    --dark: #1A1A2E;         /* Koyu tema */
    --light: #FFFFFF;        /* Açık tema */
}
```

### Görselleri Değiştirin

1. Kendi fotoğraflarınızı projeye ekleyin
2. `index.html` dosyasındaki image URL'lerini değiştirin:

```html
<!-- Öncesi -->
<img src="https://images.unsplash.com/..." alt="Fotoğraf">

<!-- Sonrası -->
<img src="images/benim-fotograf.jpg" alt="Fotoğraf">
```

### İçeriği Güncelleyin

| Bölüm | Dosya | Satır |
|--------|------|------|
| İletişim Bilgileri | `index.html` | Contact Section |
| Sosyal Medya | `index.html` | Footer |
| Hakkımda | `index.html` | About Section |
| Hizmetler | `index.html` | Services Section |
| Portfolyo | `index.html` | Portfolio Section |
