## 💡 Color Usage Guidelines

### When to Use Each Color

**Purple (Primary)**
- Main CTAs and primary actions
- Active states and selections
- Important headings

**Blue (Secondary)**
- Secondary actions
- Links and navigation
- Information elements

**Cyan (Accent)**
- Highlights and special features
- Interactive elements
- Data visualization

**Green (Success)**
- Successful operations
- Positive status
- Completion indicators

**Amber (Warning)**
- Warnings and cautions
- Pending states
- Important notices

**Red (Danger)**
- Errors and failures
- Delete actions
- Critical alerts

## 🎨 CSS Variables

All colors are defined as CSS custom properties in `styles.css`:

```css
:root {
    --primary-500: #8B5CF6;   /* Purple */
    --secondary-500: #6366F1;  /* Blue */
    --accent-500: #3B82F6;     /* Sky */
    --success-500: #10B981;    /* Green */
    --warning-500: #F59E0B;    /* Amber */
    --danger-500: #EF4444;     /* Red */
    --info-500: #06B6D4;       /* Cyan */
}
```
