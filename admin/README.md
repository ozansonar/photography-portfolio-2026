# 🎯 PHOTOGRAPHY PORTFOLIO ADMIN PANEL

## 📝 SAYFALAR

### 1. Login Sayfası (`login.html`)
- Glassmorphism tasarım
- E-posta + Şifre girişi
- Beni hatırla checkbox
- Şifremi unuttum linki
- Sosyal medya giriş (Google, Facebook)
- Kayıt ol linki
- Animasyonlu arka plan

### 2. Şifremi Unuttum (`forgot-password.html`)
- E-posta ile şifre sıfırlama
- Başarı mesajı
- Geri dönüş linki
- Animasyonlu tasarım

### 3. Ana Dashboard (`index.html`)
- 4 istatistik kartı (animated counters)
- 2 chart (Line + Doughnut)
- Son aktiviteler
- En popüler fotoğraflar
- Sidebar navigation
- Topbar (arama, tema, bildirimler)

### 4. Galeri Yönetimi (`index.html#gallery`)
- Grid/List görünüm
- Kategori filtreleri
- Fotoğraf kartları
- Düzenle/Sil aksiyonları

### 5. Blog Yönetimi (`blog-management.html`)
- Blog listesi (tablo)
- Yeni blog modal
- Düzenle/Sil butonları
- Durum badge'leri
- Arama ve filtreleme
